## What I've Been Building

Most of this work lives inside company codebases rather than public repos, so here's the shape of it:

- **EDA tooling & data-grid platform (Pyrack)** — React/Next.js/TypeScript app with a normalized Redux state layer and a client-side query caching/sync layer that cut redundant API calls by ~80% per view.
- **Real-time tracking product (Texly)** — SSR/SSG Next.js app (95+ SEO/AEO scores) with WebSocket-based live tracking and Google Maps integration holding sub-100ms state updates, deployed on AWS EC2 via GitHub Actions CI/CD.
- **OBS Stream AI Monitoring System** — native C OBS plugin for low-level packet capture and frame telemetry, paired with an FFmpeg/RTMP pipeline (network-degradation detection + auto-reconnect) and a Django backend for telemetry ingestion.
- **CRM Data Analytics Platform** — React + TypeScript analytics dashboards over a Django backend, with async batch processing, virtualized tables, and an AI chatbot for natural-language reporting; cut aggregation compute costs by ~35%.

*(These are company/production projects rather than public repos — happy to walk through the details directly.)*
